## Caso seleccionado · Mobilec

En Mobilec diseñé y construí un ecosistema coordinado entre atención
conversacional y una capa segura de integración. El sistema conecta datos,
operación y telemetría con equipos humanos y dispositivos físicos, sin
concentrar toda la responsabilidad en una sola aplicación.

```text
canales de cliente
        ↓
orquestación conversacional
        ↓
middleware seguro
        ↓
datos · operación · telemetría
        ↓
equipos humanos + dispositivos físicos
```

La representación es deliberadamente abstracta: muestra criterio de diseño sin
exponer código propietario, datos de clientes ni topología operativa sensible.

## Tecnologías en contexto

- **Asistente conversacional con IA y capa de integración segura:** JavaScript/TypeScript y Node.js para servicios e integraciones; PostgreSQL para datos; Redis/BullMQ para colas y procesamiento en segundo plano; AWS EC2 para operación.
- **Sitio corporativo de Mobilec:** React, Next.js y TypeScript para el sitio y el dashboard; Google Analytics para analítica; Firebase App Hosting para despliegues vinculados a GitHub.
- **Automatización editorial del sitio corporativo de Mobilec:** GitHub Actions ejecutaba semanalmente la actualización de noticias con Gemini.

## Stack técnico

| Área | Tecnologías | Aplicación |
|---|---|---|
| Backend e integraciones | JavaScript, TypeScript, Node.js, Express, APIs REST, webhooks | Asistente conversacional con IA y capa de integración segura |
| Datos y procesos | SQL, PostgreSQL, Supabase, Redis, BullMQ | Fuente operativa de Mobilec y procesamiento en segundo plano |
| Frontend | React, Next.js, Tailwind CSS | Sitio y dashboard corporativo de Mobilec; sitio de Jit De Flou |
| IA y voz | OpenAI con tool calling y transferencia humana; Twilio Media Streams y WebSockets | Asistente conversacional con IA; voz en tiempo real implementada y probada durante mi etapa en Mobilec |
| Seguridad | JWT, OAuth 2.0, validación con Zod, verificación de webhooks y gestión de secretos | Servicios e integraciones de Mobilec; AWS Secrets Manager en la operación |
| Nube y calidad | AWS EC2, Google Cloud, Firebase App Hosting, PM2, systemd, Vitest, Supertest y GitHub Actions | Operación de Mobilec; TopBot; despliegues y automatización editorial del sitio corporativo de Mobilec con Gemini |
