CASO SELECCIONADO · MOBILEC SATELITAL

Un ecosistema operativo,
no un chatbot.

El asistente conversacional con IA y la capa de integración segura conectan conversación, datos, operación y dispositivos físicos. El canal conversacional y las integraciones críticas tienen responsabilidades separadas. Este caso describe mi trabajo hasta septiembre de 2026; no implica mantenimiento actual a mi cargo.

CUATRO DECISIONES

  1. 01

    Proteger

    La integración crítica permanece aislada del canal conversacional.

  2. 02

    Unificar

    Los datos de servicios externos convergen en una fuente operativa común.

  3. 03

    Supervisar

    Las acciones sobre dispositivos físicos conservan validación y control humano.

  4. 04

    Preservar

    Funciones opcionales, como voz o monitoreo proactivo, pueden desactivarse sin detener el núcleo conversacional.

TECNOLOGÍAS EN CONTEXTO

Node.js y Express en el asistente conversacional con IA y la capa de integración segura; Supabase/PostgreSQL para datos, Redis/BullMQ para procesos y AWS Secrets Manager para secretos.

Web y despliegue

React, Next.js, TypeScript y Tailwind CSS en el sitio corporativo de Mobilec y proyectos web de Jit De Flou; Firebase App Hosting para sus despliegues.

IA, voz y automatización

OpenAI con tool calling y transferencia humana en el asistente conversacional con IA; Twilio Media Streams y WebSockets en voz en tiempo real implementada y probada; GitHub Actions y Gemini en el sitio corporativo de Mobilec.
