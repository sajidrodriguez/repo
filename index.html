CASO SELECCIONADO · MOBILEC SATELITAL

Un ecosistema operativo,
no un chatbot.

Mobibot AI y Mobilec Hub conectan conversación, datos, operación y dispositivos físicos. El canal conversacional y las integraciones críticas tienen responsabilidades separadas. Este caso describe mi trabajo hasta septiembre de 2026; no implica mantenimiento actual a mi cargo.

CUATRO DECISIONES

  1. 01

    Proteger

    La integración crítica permanece aislada del canal conversacional.

  2. 02

    Unificar

    Los datos de servicios externos convergen en una fuente operativa común.

  3. 03

    Supervisar

    Las acciones sobre dispositivos físicos conservan validación y control humano.

  4. 04

    Preservar

    Funciones opcionales, como voz o monitoreo proactivo, pueden desactivarse sin detener el núcleo conversacional.

TECNOLOGÍAS EN CONTEXTO

Servicios y datos

JavaScript/TypeScript y Node.js en Mobibot AI y Hub; PostgreSQL para datos, Redis/BullMQ para colas y AWS EC2 para operación.

Web y analítica

React, Next.js y TypeScript en WebCorp: sitio público, dashboard autenticado y Google Analytics para administración y ventas.

Despliegue y automatización

Firebase App Hosting para desplegar WebCorp desde GitHub; GitHub Actions y Gemini para actualizar noticias cada semana.
